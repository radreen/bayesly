## Топ-проблеми (від найважливішої)

### 1. Розклад GitHub ненадійний — бот «спить»
За 20.11 GitHub запустив лише 2 перевірки за розкладом; з 15:42 до 17:07 UTC — жодної (тики о :00/:15/:30/:45
GitHub під навантаженням затримує або пропускає). Наслідок: мало постів, команди в Telegram без відповіді.
- **Зроблено:** тики перенесено на :07/:22/:37/:52.
- **Надійне рішення (рекомендую):** зовнішній безкоштовний будильник cron-job.org кожні 10 хв викликає наш
  workflow через GitHub API. Потрібно від тебе: акаунт cron-job.org + GitHub-токен з правом «Actions: write»
  (вставляєш сам). Альтернатива: Cloudflare Worker (заодно дає миттєві відповіді бота).

### 2. Нуль аудиторії: бот постить у порожнечу
Нові акаунти без підписників отримують одиниці переглядів, а алгоритми Threads/Instagram спершу показують
пости підписникам. Саме лише автопостинг аудиторію не збере.
- Заповнити профілі за `docs/profile-kit.md` (bio, аватар, шапка X) і закріпити пост «Що таке Bayesly».
- Перші 2 тижні — ручна активність 15–20 хв/день: змістовні відповіді під постами великих AI-акаунтів у Threads
  (там відповіді — головний канал росту), підписки на нішу.
- Reels — головний шлях до нових людей в Instagram (показуються не-підписникам); тримати 3–5 Reels/день.
- Threads підтримує тему поста (topic tag) — додати автоматично (перевірю API).

### 3. Не ті теми
2 з 3 постів — технічні блоги AWS («як налаштувати SageMaker»). Конкуренти виграють на іменах, грошах і
вірусних історіях. Рейтинг уже переписано (відомі імена, гроші, свіжість; AWS/NVIDIA урізано), але:
- прибрати AWS ML Blog і NVIDIA Developer Blog зовсім або пускати лише анонси;
- додати швидкі джерела великих історій: Google News RSS за запитами (OpenAI, Anthropic, Gemini, NVIDIA, Apple AI),
  Hacker News (топ), офіційні newsroom (Anthropic — без RSS, треба читати сторінку).

### 4. Повільно для «бути першим»
0,9–5 год від новини до поста. Причини: рідкі запуски (п.1) + RSS повільніший за X, де новини з'являються першими.
- Після п.1 очікувано 15–30 хв для RSS-джерел.
- Швидше — моніторинг X-акаунтів компаній через X API (платне читання, оцінка кілька $/міс) — вирішувати після п.1–3.

### 5. Мало «живого» відео
На сторінках джерел відео майже немає (перевірено 27 статей: 1 mp4, 1 YouTube). Зараз у Reels: фото з рухом +
прокрутка самої статті. Варіанти, щоб відео було цікавіше:
| Варіант | Ціна | Ризик |
|---|---|---|
| Стокові відео Pexels/Pixabay за темою (сервери, роботи, код) | безкоштовно, потрібен API-ключ | немає (ліцензія дозволяє) |
| AI-відео (Veo через Gemini API) під кожну новину | платно | немає, але треба мітка «AI» |
| Кліпи з X/YouTube компаній | X-читання платне; YouTube завантаження заборонене правилами | авторське право, бани |
**Рекомендую:** Pexels зараз (потрібен безкоштовний ключ), Veo — тест на 5–10 відео.

### 6. Немає даних для рішень
Метрики ніде не збираються. Пропоную щоденний збір (перегляди/лайки/відповіді Threads, лайки/коментарі Instagram,
підписники) у `ci-state/metrics.json` + ранкове зведення в Telegram. Для охоплення Instagram потрібне ще право
`instagram_manage_insights`.

### 7. Повільні відповіді на коментарі
Ти відповідаєш сам, але про нові коментарі не знаєш. Бот може слати в Telegram «новий коментар під постом X»
з кнопкою на пост — швидка відповідь у першу годину підсилює охоплення.

### 8. Дублікати однієї історії з різних джерел
Techmeme і The Verge пишуть про те саме різними словами; поточний фільтр ловить лише схожі заголовки.
Ризик — два пости про IPO Anthropic поспіль. Рішення: перед публікацією коротка перевірка Gemini
«це та сама історія, що ми вже публікували за 48 год?».

### 9. Фактичні помилки без людини
Пости йдуть без перевірки людиною. Вже є: «лише факти з джерела», фільтр якості. Додати: окремий дешевий
прохід Gemini «звір пост з джерелом, знайди твердження, яких там немає» перед публікацією.

### 10. Обмеження і ризики інфраструктури
- Озвучка: 10 запитів/добу на модель (≈20 відео/день) — платний тариф Google <1 цент/відео знімає ліміт.
- Фото з джерел часто з фотоагентств (Getty): підпис «Image: …» є, але ризик скарги лишається. Можна віддавати
  перевагу офіційним зображенням компаній і пропускати фото з позначкою Getty.
- Вартість відео в X не вказана в документації — перевірити в console.x.com → Usage після кількох днів.
- TikTok (аудит), YouTube Shorts (Google OAuth) ще не підключені.

## План (що робити першим)
1. Надійний будильник (п.1) — без цього все інше працює вполовину.
2. Профілі + закріплений пост + 2 тижні ручної активності (п.2) — це твоя частина.
3. Джерела великих історій і відсів технічних блогів (п.3).
4. Метрики + сповіщення про коментарі (п.6–7).
5. Pexels-відео (п.5), антидублікати і фактчек (п.8–9).
