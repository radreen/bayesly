# Bayesly logo — wordmark

**bayesly** in **Funnel Display Bold**, tracking **−35** (−0.035 em), lowercase. No separate symbol.
Funnel Display is on Google Fonts under the SIL Open Font License, so it is free to use in a logo.

## Files

| File | Use |
|---|---|
| `bayesly-wordmark-ink.svg` | Main logo: on lime or light backgrounds |
| `bayesly-wordmark-paper.svg` | On black / dark backgrounds |
| `bayesly-wordmark-lime.svg` | On black only (never on light backgrounds: too little contrast) |
| `bayesly-avatar-lime.png` / `.svg` | Profile picture for Threads / X (1000×1000, black **b** on lime; platforms crop it to a circle) |
| `bayesly-avatar-ink.png` | Alternative profile picture (lime **b** on black) |
| `construction-ink.png`, `construction-lime.png` | Construction and clear space |

SVG text is outlined: it looks the same everywhere without the font installed.

## Rules

- **Clear space:** at least **u** on every side, where u = ½ x-height (see the construction boards).
- **Colours:** `#0D0D0E` black, `#C6FF2E` lime, `#F5F5F0` paper. One colour per logo, no gradients, no outlines, no shadows.
- **Don't:** stretch, re-space, retype it in another font, add the old dot, or put the lime version on light backgrounds.
- **Minimum size:** about 64 px wide on screen; below that use the avatar **b**.
